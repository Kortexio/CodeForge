# C01 — RouteId

Depends on: —

Value object `Acme.Router.RouteId` (file `src/Acme.Router/RouteId.cs`).

## Acceptance criteria

- `RouteId.Create(string value)` returns a `RouteId`; `Value` is the text with leading and trailing whitespace trimmed.
- Empty / whitespace only / `null` → `ArgumentException` with message `ROUTE_ID_EMPTY`.
- More than 32 characters (after trim) → `ArgumentException` with message `ROUTE_ID_TOO_LONG`.
- Equality is case-insensitive: `RouteId.Create("Home") == RouteId.Create("home")` is `true`
  and both have the same `GetHashCode()`.
- `ToString()` returns `Value`.
