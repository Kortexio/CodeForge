# C05 — Resolve with priorities

Depends on: C03, C04

Add to `RouteTable` the method `RouteMatch? Resolve(string method, string path)` and the
record `Acme.Router.RouteMatch(Route Route, IReadOnlyDictionary<string, string> Values)`.

## Acceptance criteria

- Only routes with the same method (case-insensitive) are considered.
- A matching literal route always wins over a parametric route (`RoutePattern`).
- Among several matching routes of the same kind, the one with the highest `Priority` wins;
  on a tie, the one added first wins.
- Literal route → `Values` empty; parametric route → the values from `RoutePattern.TryMatch`.
- No match → `null`.
- `Match` (C03) keeps working for literal routes only.
