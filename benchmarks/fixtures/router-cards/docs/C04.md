# C04 — RoutePattern (path parameters)

Depends on: C02

Static class `Acme.Router.RoutePattern` (file `src/Acme.Router/RoutePattern.cs`).

## Acceptance criteria

- `bool IsParametric(string pattern)` — `true` if any segment is `{name}`.
- `bool TryMatch(string pattern, string path, out IReadOnlyDictionary<string, string> values)`:
  - compares segment by segment (separator `/`), same number of segments;
  - literal segments compare case-insensitively;
  - `{name}` accepts any non-empty segment and stores it in `values["name"]`
    (the dictionary keys are case-insensitive);
  - no match → `false` and `values` empty.
- Example: `TryMatch("/users/{id}/orders/{orderId}", "/users/42/orders/7", out v)` → `true`,
  `v["id"] == "42"`, `v["orderId"] == "7"`.
