# C03 — RouteTable (literal routes)

Depends on: C02

Class `Acme.Router.RouteTable` (file `src/Acme.Router/RouteTable.cs`).

## Acceptance criteria

- `void Add(Route route)`:
  - same `Method` + same `Path` (case-insensitive) already registered → `InvalidOperationException` with message `DUPLICATE_ROUTE`;
  - same `Id` already registered → `InvalidOperationException` with message `DUPLICATE_ID`.
- `int Count` — number of routes.
- `Route? Match(string method, string path)` — the route with the same method (case-insensitive)
  and the same path (case-insensitive, trailing `/` ignored); `null` if there is none.
