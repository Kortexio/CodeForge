# C02 — Route

Depends on: C01

Entity `Acme.Router.Route` (file `src/Acme.Router/Route.cs`).

## Acceptance criteria

- `new Route(RouteId id, string method, string path, int priority = 0)`.
- `Method` is stored in upper case; only `GET`, `POST`, `PUT`, `DELETE` are accepted
  (anything else → `ArgumentException` with message `METHOD_NOT_SUPPORTED`).
- `Path` must start with `/` (otherwise `ArgumentException` with message `PATH_INVALID`);
  a trailing `/` is removed, except for the root path `/`.
- `Priority` cannot be negative (`ArgumentOutOfRangeException`).
- Read-only properties: `Id`, `Method`, `Path`, `Priority`.
