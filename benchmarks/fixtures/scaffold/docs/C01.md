# C01 — Solution, projects and architecture test (lite)

**Stack:** .NET 10, nullable enable.

## Goal

Create the empty solution with its projects and a test that prevents forbidden dependencies.

## Create

At the workspace root:

1. Solution `Acme.Router` (`.sln` or `.slnx` file).
2. Optional but recommended: `Directory.Build.props` with `TargetFramework` net10.0, `Nullable` enable, `ImplicitUsings` enable.
3. Projects:
   - `src/Acme.Router.Domain` — classlib
   - `src/Acme.Router.Application` — classlib that **references** Domain
   - `tests/Acme.Router.ArchitectureTests` — xunit that references Domain and Application
4. Add all of them to the solution.

## Architecture rule (required)

In `tests/Acme.Router.ArchitectureTests`, a Fact test that fails if `Acme.Router.Domain` references `Acme.Router.Application`.

Accepted example:

```csharp
using System.Reflection;
using Xunit;

public class ArchitectureTests
{
    [Fact]
    public void Domain_does_not_reference_Application()
    {
        var domain = Assembly.Load("Acme.Router.Domain");
        var forbidden = domain.GetReferencedAssemblies()
            .Any(a => a.Name == "Acme.Router.Application");
        Assert.False(forbidden);
    }
}
```

## Done when

`dotnet test` at the root passes (architecture test green).

## Do not

- Do not use `tail`, `grep` or Unix pipes in Windows `cmd.exe`.
- Do not create experimental `tmp*` folders — write the final projects.
