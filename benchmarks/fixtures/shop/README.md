# shop

Small pricing library for a shopping cart (CommonJS, no dependencies).

- `src/cart/` — cart operations and totals
- `src/pricing/` — tax, discount rules and coupons
- `src/checkout/` — invoice building and formatting
- `config/` — coupon definitions
- `docs/pricing.md` — business rules

Run the tests with `npm test` (Node's built-in test runner).
