## What's new since v0.2.0

### Agents window
- Code-OSS Agents / sessions UI runs CodeForge's harness: models, Ask/Plan/Agent, permissions, slash commands, discovery
- Not a second, thinner agent

### Vision in chat
- Paste or panel-wide drag-and-drop
- Auto-route the turn to a reachable vision-capable model
- If no vision server is up, drop the image — keep the turn
- Attachments survive compaction and the token estimate

### Universal tool recovery
- Family-aware repair: Qwen, DeepSeek, Llama, Gemma, Mistral, Harmony, and related locals
- Schema repair, phantom tool-use retry, thinking-field handling

### Language-agnostic oracle
- Agent records build/test with `set_verify_command` (or `none` + reason)
- IDE re-runs those commands after writes; green is exit 0

### Loop hardening
- Finish gates after `update_status`; leaked `next` calls cut; echoed harness notes ignored
- Structural gates for CS2 / CS3 / CS4 / CS6 live-run losses
- Parallel reads, mid-turn steering, hooks, effect gate, terminate
- `<thought>`-only replies no longer end the turn

### Bench
- Headless T1–CS6 on the same scorer
- Optional Aider / OpenHands baselines (`benchmarks/externalAgents.mjs`)

## Not in this release

- Authenticode / SmartScreen-clean installer
- macOS / Linux packages
- Five-minute onboarding
- Agent CORE expansion (glob, wiki, media, notebook as defaults) — `feat/core-tool-surface`
- Parallel multi-session LLM slots (in progress on `feat/parallel-session-slots`, untested e2e)
- Intent crutches
- Claiming 100 on every CS5 run

## Install

1. Download `CodeForge-Setup-0.3.0-win32-x64.exe`
2. Run the installer (per-user under `%LOCALAPPDATA%\Programs\CodeForge`)
3. Open Settings → AI → point at your OpenAI-compatible endpoint (llama.cpp, Ollama, vLLM, cloud APIs…)
4. Pick a model → Agent mode → ship

No Docker. No vendor lock-in. Your models. Your machine.
